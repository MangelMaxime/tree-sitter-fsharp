# The compiler service's parser ERROR-RECOVERY fixture tree. 42% of its 985 files

# and the bodies are things like `let (i:)`, `inherit` with no type, `a +` with no
# operand, and an empty `` `` `` identifier. None carry an <Expects> annotation, so
# the classifier files them as valid and the corpus then punishes a parser for
# correctly rejecting them. Excluding the tree costs 564 genuinely valid samples
